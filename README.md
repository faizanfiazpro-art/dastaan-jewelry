## Deploy on GitHub Pages
Upload all files and folders to the root of your `dastaan-jewelry` repository:

- index.html
- style.css
- script.js
- assets folder
- README.md

Then go to Settings > Pages and choose:
- Source: Deploy from a branch
- Branch: main
- Folder: / root

Commit changes and wait a few minutes.
